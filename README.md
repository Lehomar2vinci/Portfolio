# Portfolio — Lehomar2vinci

Mon portfolio / CV personnel — site statique en HTML, CSS et JavaScript.

## Structure

```
Portfolio/
├── index.html       # Page principale
├── css/
│   └── style.css    # Styles (thème sombre, responsive)
├── js/
│   └── main.js      # Interactivité (menu mobile, animations au défilement)
└── cv.pdf           # CV téléchargeable (à ajouter)
```

## Sections

- **Hero** — accroche avec prénom et titre
- **À propos** — présentation courte
- **Compétences** — stack technique (Web, Mobile, Jeux, Multimédia…)
- **Projets** — cartes de projets GitHub
- **Contact** — lien GitHub

## Utilisation

Ouvrir `index.html` directement dans un navigateur ou déployer sur GitHub Pages / Netlify / Vercel.

Pour activer le téléchargement du CV, placer un fichier `cv.pdf` à la racine du projet.
